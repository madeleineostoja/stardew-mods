# Part of a Saloon Breakfast (patched)

A patched copy of [Part of a Saloon Breakfast by Agent Lyoko](https://www.nexusmods.com/stardewvalley/mods/17775).

This is a complete Content Patcher pack, not a diff or an add-on to install alongside the original. It retains the original author, mod ID, and Nexus update key. Upstream code and assets remain subject to their authors' licensing; this repository does not relicense them. Check upstream redistribution permissions before publishing a package.

## Installation

1. Install [SMAPI](https://smapi.io/) and [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915).
2. Remove the original Part of a Saloon Breakfast folder, retaining your `config.json` if needed.
3. Extract this package's `PartOfASaloonBreakfast` folder into `Stardew Valley/Mods`.
4. Launch through SMAPI.

Do not install both copies: they share `agentlyoko.stardropbreakfast`. SMAPI's Nexus update checks refer to the upstream mod, not this patched variant.

The patch's package version is maintained in its own `manifest.json`, independently of the other packages in this repository.
